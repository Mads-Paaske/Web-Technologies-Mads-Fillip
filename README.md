# The Pet EmPAWrium
This project is made by Mads Paaske Rasmussen(madsp24) and Fillip Essmann Davidsen(fidav24). The project is coded in our github repo: https://github.com/Mads-Paaske/Web-Technologies-Mads-Fillip

## Choose a topic
Our choice of topic is creating a website for a pet shelter where pet shelters and private users can create listings for pets and adopt pets.

## Topic motivation
When looking to adopt a pet you have to either use the individual pet shelter's own website or a website like DBA where private users can put up a litter of kittens up for adoption for example. 
Our goal is to allow these two userbases to use the same platform, which will make it easier for users looking to adopt a pet as all their options are collected on one site.

## Why develop a web solution?
When developing a solution like this there are going to be a lot of reads and writes to the database containing all the pets up for adoption. If the user ran this on a their own machine new versions of the 
website would have to be installed by the user each time a change was made in the database for example in the case that a pet got adopted. Buliding a web solution also improves the reach of the program as 
new users won't have to install anything in order browse the selection of pets which can be a barrier for certain users.
